# P1.5 Thesis Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settle ledger rows T1–T5 on real data (Django history, the v1 E5 repos) using only the P1 region engine, before P2 starts.

**Architecture:** One small measurement library (`packages/indexer/thesis/lib.ts`: git access, line hunks, rebasing one commit's hunks under another, changed-region sets) with unit tests, plus one script per claim. Pass bars are fixed in this plan **before** any script runs; a result that misses its bar is recorded as `refuted` or `partial`, never re-tuned.

**Tech Stack:** TypeScript run with `tsx`, vitest 2.1.8, `diff` (already an indexer dependency), git, Django's own `tests/runtests.py` in the v1 bench venv.

**Spec:** `docs/specs/2026-10-15-loom-v2-design.md` §3.5, §3.9, §3.10, §6.6, §10.1.

## Pre-registered claims and bars

| Row | Claim as tested | Sample | Bar |
|---|---|---|---|
| T1 | When two commits touch the same Python file within a week, they usually touch different regions | Consecutive first-parent revisions (C1, C2) of a `.py` file in the last 3,000 first-parent commits, author dates ≤ 7 days apart, all three maps clean | > 50% of pairs region-disjoint |
| T2a | regionMerge never changes a merge git already resolves | Every real Django merge: each `.py` file changed on both sides (55 files, smoke S-16) | regionMerge text == git text on 100% |
| T2b | regionMerge resolves touching-hunk conflicts correctly and makes no wrong merges | T1 pairs whose C2 hunks can be re-based under C1 (theirs = C2's change applied to C1's base; truth = file at C2) | 0 wrong merges (merged ≠ truth); report the share of git conflicts resolved |
| T3 | Region ids survive history: a region whose text did not change keeps its id | Every base→C1 transition in the T1 window (no date filter) | ≤ 0.5% id churn for unchanged-text `definition`/`container` regions; gaps reported without a bar; 20 detected renames printed and inspected |
| T4 | Impact (reverse CALLS/TESTS, 3 hops) predicts which tests break on a contract change | Each A patch reduced to its definition-file hunks only (no caller or test fixes), full Django suite run serially | pooled recall ≥ 0.8 at test-method level over patches that break ≥ 1 test; precision reported |
| T5 | Every E5 merge conflict is in a class v2 handles: regionMerge resolves it, or it is a same-region edit that v2 leases serialize | The 6 E5 team-1 repos, agent branches landed in commit-time order through `git merge`, then regionMerge on each conflicted file | 0 conflicts outside those two classes; counts reported per class |

T5 does not show that agents would succeed under v2; E5-v2 (P3) shows that. T1 uses sequential commits as a stand-in for concurrent work: a follow-up commit tends to touch the same code, so this stand-in is biased toward overlap, which is the conservative direction.

## Review Focus

1. **A file missing at C1^ or C2** (added or deleted file): skip the pair and count it; never crash.
2. **A parse error at any of the three revisions:** skip and count as `degraded`. T1/T2 report the skip count.
3. **A last line without a newline:** the hunk round trip must be exact. Unit test `roundtrip keeps a missing final newline`.
4. **Insertions at the same base point by both sides:** ordering is ambiguous. Construction is self-checked (combined application must equal C2); a mismatch is counted as `construct_mismatch` and excluded, never "fixed".
5. **A test already failing on the clean tree** (smoke: 1 i18n msgfmt failure): subtracted by the baseline run, never counted as a hit or a miss.
6. **A Django test run that crashes before any test runs** (an import error at startup): recorded as `suite_crash` for that patch and excluded from recall, counted in the report.

```ts
import { execFileSync } from 'node:child_process';
import { mkdirSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { diffLines } from 'diff';
import type { RegionDiff } from '../src/regions/index.js';

export const ROOT = fileURLToPath(new URL('../../../', import.meta.url));
export const git = (repo: string, ...args: string[]): string =>
  execFileSync('git', ['-C', repo, ...args], { encoding: 'utf8', maxBuffer: 1 << 28, stdio: ['ignore', 'pipe', 'ignore'] });
export function show(repo: string, rev: string, path: string): string | null {
  try { return git(repo, 'show', `${rev}:${path}`); } catch { return null; }
}

export const splitLines = (t: string): string[] => t.match(/[^\n]*\n|[^\n]+$/g) ?? [];

/** Replace old lines [o, o+oLen) with `lines`. Hunks are sorted and disjoint in old coordinates. */
export interface Hunk { o: number; oLen: number; lines: string[] }

export function hunks(a: string, b: string): Hunk[] {
  const out: Hunk[] = []; let o = 0; let cur: Hunk | null = null;
  for (const c of diffLines(a, b)) {
    const ls = splitLines(c.value);
    if (!c.added && !c.removed) { if (cur) { out.push(cur); cur = null; } o += ls.length; continue; }
    cur ??= { o, oLen: 0, lines: [] };
    if (c.removed) { cur.oLen += ls.length; o += ls.length; } else cur.lines.push(...ls);
  }
  if (cur) out.push(cur);
  return out;
}

export function applyHunks(text: string, hs: Hunk[]): string {
  const L = splitLines(text); const out: string[] = []; let i = 0;
  for (const h of hs) { out.push(...L.slice(i, h.o), ...h.lines); i = h.o + h.oLen; }
  return out.concat(L.slice(i)).join('');
}

/**
 * c1: base→ours. c2: ours→c2. Returns c2's hunks moved into base coordinates, so that
 * applyHunks(base, theirs) is "C2's change made on C1's base". Overlap = c2 rewrites a line c1 wrote.
 * touch = some c2 hunk is adjacent to (or a point on the boundary of) a c1 span.
 */
export function rebaseUnder(c1: Hunk[], c2: Hunk[]): { kind: 'overlap' } | { kind: 'ok'; theirs: Hunk[]; touch: boolean } {
  let shift = 0;
  const spans = c1.map((h) => { const n = h.o + shift; shift += h.lines.length - h.oLen; return { n, nEnd: n + h.lines.length, delta: h.lines.length - h.oLen }; });
  const theirs: Hunk[] = []; let touch = false;
  for (const h of c2) {
    const a = h.o, b = h.o + h.oLen;
    let d = 0;
    for (const s of spans) {
      if (a < s.nEnd && s.n < b) return { kind: 'overlap' };
      if ((s.n < a && a < s.nEnd) || (s.n < b && b < s.nEnd)) return { kind: 'overlap' };
      if (b === s.n || a === s.nEnd || (a === b && s.n <= a && a <= s.nEnd)) touch = true;
      if (s.nEnd <= a && !(a === b && a === s.n && s.n === s.nEnd)) d += s.delta;
    }
    theirs.push({ o: a - d, oLen: h.oLen, lines: h.lines });
  }
  return { kind: 'ok', theirs, touch };
}

/** Region ids in the *middle* map that a diff touches: side 'new' for base→mid, 'old' for mid→next. */
export function changedIn(diff: RegionDiff, side: 'new' | 'old'): Set<string> {
  return side === 'new'
    ? new Set([...diff.updated, ...diff.created, ...diff.renamed.map((r) => r.to)])
    : new Set([...diff.updated, ...diff.tombstoned, ...diff.renamed.map((r) => r.from)]);
}

export function writeResult(id: string, text: string, json: unknown): void {
  const dir = join(ROOT, 'bench/results'); mkdirSync(dir, { recursive: true });
  writeFileSync(join(dir, `${id}.txt`), text);
  writeFileSync(join(dir, `${id}.json`), JSON.stringify(json, null, 1));
}
```

```ts
import { join } from 'node:path';
import { diffRegions, gitMergeFile, regionMerge, regionize, type FileRegions } from '../src/regions/index.js';
import { applyHunks, changedIn, git, hunks, rebaseUnder, ROOT, show, writeResult } from './lib.js';

const REPO = join(ROOT, 'bench/cache/django.git');
const WINDOW = 3000, DAYS = 7;

// first-parent commits, newest first, with the .py files each changed
const log = git(REPO, 'log', '--first-parent', `-n${WINDOW}`, '--format=@%H %P %at', '--name-only', '--diff-filter=M', '--', '*.py');
const revs = new Map<string, Array<{ c: string; p: string; at: number }>>();
let cur: { c: string; p: string; at: number } | null = null;
for (const line of log.split('\n')) {
  if (line.startsWith('@')) { const [c, p, ...rest] = line.slice(1).split(' '); cur = { c, p, at: Number(rest.at(-1)) }; continue; }
  if (line && cur) (revs.get(line) ?? revs.set(line, []).get(line)!).push(cur);
}

const maps = new Map<string, FileRegions | null>();
async function map(rev: string, path: string): Promise<FileRegions | null> {
  const k = `${rev}:${path}`; if (maps.has(k)) return maps.get(k)!;
  const t = show(REPO, rev, path); const m = t === null ? null : await regionize(path, t);
  const v = m && !m.degraded ? m : null; maps.set(k, v); return v;
}

const t1 = { pairs: 0, disjoint: 0, sameRegion: 0, skipped: 0 };
const t2 = { overlap: 0, built: 0, mismatch: 0, touch: 0, gitConflict: 0, rmResolved: 0, rmConflict: 0, rmUnsupported: 0, wrong: 0, gitWrong: 0, examples: [] as string[] };
const t3 = { transitions: 0, defs: 0, defChurn: 0, gaps: 0, gapChurn: 0, churnExamples: [] as string[], renames: [] as string[] };

for (const [path, list] of revs) {
  const chron = [...list].reverse();                     // oldest first
  for (let i = 0; i < chron.length; i++) {
    const c1 = chron[i];
    const base = await map(c1.p, path), ours = await map(c1.c, path);
    if (!base || !ours) { t1.skipped++; continue; }
    // T3: every base→C1 transition
    t3.transitions++;
    const d1 = diffRegions(base.regions, ours.regions);
    const seen = new Map(ours.regions.map((r) => [r.hash + '|' + r.kind, r.id]));
    const dupe = new Set<string>(); const cnt = new Map<string, number>();
    for (const r of [...base.regions, ...ours.regions]) { const k = r.hash + '|' + r.kind; cnt.set(k, (cnt.get(k) ?? 0) + 1); }
    for (const [k, n] of cnt) if (n !== 2) dupe.add(k);
    for (const r of base.regions) {
      const k = r.hash + '|' + r.kind; if (dupe.has(k) || !seen.has(k)) continue;
      const def = r.kind === 'definition' || r.kind === 'container';
      if (def) t3.defs++; else if (r.kind === 'gap') t3.gaps++; else continue;
      if (seen.get(k) !== r.id) {
        if (def) { t3.defChurn++; if (t3.churnExamples.length < 20) t3.churnExamples.push(`${c1.c.slice(0, 10)} ${r.id} → ${seen.get(k)}`); }
        else t3.gapChurn++;
      }
    }
    for (const rn of d1.renamed) if (t3.renames.length < 20) t3.renames.push(`${c1.c.slice(0, 10)} ${rn.from} → ${rn.to}`);

    // T1/T2b: consecutive revision within DAYS
    const c2 = chron[i + 1];
    if (!c2 || c2.at - c1.at > DAYS * 86400 || c2.p !== c1.c && show(REPO, c2.p, path) !== ours.text) continue;
    const next = await map(c2.c, path);
    if (!next) { t1.skipped++; continue; }
    t1.pairs++;
    const a = changedIn(d1, 'new'), b = changedIn(diffRegions(ours.regions, next.regions), 'old');
    if ([...a].some((x) => b.has(x))) t1.sameRegion++; else t1.disjoint++;

    const r = rebaseUnder(hunks(base.text, ours.text), hunks(ours.text, next.text));
    if (r.kind === 'overlap') { t2.overlap++; continue; }
    const theirs = applyHunks(base.text, r.theirs);
    const g = gitMergeFile(base.text, ours.text, theirs);
    t2.built++; if (r.touch) t2.touch++;
    if (g.clean && g.text !== next.text) t2.gitWrong++;
    if (!g.clean) t2.gitConflict++;
    const m = await regionMerge(path, base.text, ours.text, theirs);
    if (m.status === 'merged' && m.text !== next.text) { t2.wrong++; if (t2.examples.length < 10) t2.examples.push(`${path} ${c1.c.slice(0, 10)}..${c2.c.slice(0, 10)}`); }
    if (!g.clean) {
      if (m.status === 'merged' && m.text === next.text) t2.rmResolved++;
      else if (m.status === 'conflict') t2.rmConflict++;
      else if (m.status === 'unsupported') t2.rmUnsupported++;
    }
  }
}

const pct = (x: number, n: number) => (n ? ((100 * x) / n).toFixed(1) : '—') + '%';
const v1 = t1.disjoint / t1.pairs > 0.5;
const v2 = t2.wrong === 0;
const churn = t3.defChurn / t3.defs;
const v3 = churn <= 0.005;
writeResult('t1', [
  `T1 sample: consecutive first-parent revisions of a .py file, last ${WINDOW} commits, ≤${DAYS} days apart, clean maps`,
  `bar: > 50% region-disjoint`,
  `pairs=${t1.pairs} disjoint=${t1.disjoint} (${pct(t1.disjoint, t1.pairs)}) same-region=${t1.sameRegion} skipped(missing/degraded)=${t1.skipped}`,
  `T1: ${v1 ? 'PASS' : 'FAIL'} (${pct(t1.disjoint, t1.pairs)} of ${t1.pairs})`, ''].join('\n'), t1);
writeResult('t2b', [
  `T2b sample: T1 pairs; theirs = C2's hunks rebased under C1; truth = file at C2`,
  `bar: 0 wrong merges (regionMerge merged ≠ truth)`,
  `line-overlap (not constructible)=${t2.overlap} built=${t2.built} touching=${t2.touch}`,
  `git: conflicts=${t2.gitConflict} clean-but-wrong=${t2.gitWrong}`,
  `regionMerge on git conflicts: resolved-correctly=${t2.rmResolved} (${pct(t2.rmResolved, t2.gitConflict)}) still-conflict=${t2.rmConflict} unsupported=${t2.rmUnsupported}`,
  `regionMerge wrong merges=${t2.wrong} ${t2.examples.join(' ; ')}`,
  `T2b: ${v2 ? 'PASS' : 'FAIL'} (wrong=${t2.wrong}, resolved ${t2.rmResolved}/${t2.gitConflict} git conflicts)`, ''].join('\n'), t2);
writeResult('t3', [
  `T3 sample: every base→C1 transition of a .py file in the last ${WINDOW} first-parent commits (unique-text regions only)`,
  `bar: ≤ 0.5% id churn on unchanged definition/container regions`,
  `transitions=${t3.transitions} defs=${t3.defs} churn=${t3.defChurn} (${(100 * churn).toFixed(3)}%) gaps=${t3.gaps} gap-churn=${t3.gapChurn} (${pct(t3.gapChurn, t3.gaps)})`,
  `churn examples:`, ...t3.churnExamples.map((x) => '  ' + x),
  `renames (first 20, inspect by hand):`, ...t3.renames.map((x) => '  ' + x),
  `T3: ${v3 ? 'PASS' : 'FAIL'} (${(100 * churn).toFixed(3)}% of ${t3.defs})`, ''].join('\n'), t3);
console.log([v1, v2, v3].map((v, i) => `T${['1', '2b', '3'][i]} ${v ? 'PASS' : 'FAIL'}`).join(' · '));
```

```ts
import { join } from 'node:path';
import { gitMergeFile, regionMerge } from '../src/regions/index.js';
import { git, ROOT, show, writeResult } from './lib.js';

const REPO = join(ROOT, 'bench/cache/django.git');
const r = { merges: 0, files: 0, gitClean: 0, same: 0, differ: [] as string[], rmConflict: 0, unsupported: 0, matchesM: 0 };
for (const m of git(REPO, 'rev-list', '--merges', 'HEAD').trim().split('\n')) {
  const [p1, p2] = git(REPO, 'rev-parse', `${m}^1`, `${m}^2`).trim().split('\n');
  let b: string; try { b = git(REPO, 'merge-base', p1, p2).trim(); } catch { continue; }
  r.merges++;
  const side = (p: string) => new Set(git(REPO, 'diff', '--name-only', b, p, '--', '*.py').trim().split('\n').filter(Boolean));
  const s1 = side(p1), s2 = side(p2);
  for (const f of [...s1].filter((x) => s2.has(x))) {
    const base = show(REPO, b, f), ours = show(REPO, p1, f), theirs = show(REPO, p2, f);
    if (base === null || ours === null || theirs === null) continue;
    r.files++;
    const g = gitMergeFile(base, ours, theirs);
    const x = await regionMerge(f, base, ours, theirs);
    if (g.clean) r.gitClean++;
    if (x.status === 'merged') { if (g.clean && x.text === g.text) r.same++; else r.differ.push(`${m.slice(0, 10)} ${f}`); if (x.text === show(REPO, m, f)) r.matchesM++; }
    else if (x.status === 'conflict') r.rmConflict++; else r.unsupported++;
  }
}
const ok = r.differ.length === 0 && r.same === r.gitClean;
writeResult('t2a', [
  `T2a sample: every Django merge commit; each .py file changed on both sides`,
  `bar: regionMerge text == git merge-file text on every file git merges cleanly`,
  `merges=${r.merges} files=${r.files} git-clean=${r.gitClean} identical=${r.same} differ=${r.differ.length} rm-conflict=${r.rmConflict} unsupported=${r.unsupported} rm==commit=${r.matchesM}`,
  ...r.differ.map((d) => '  differs: ' + d),
  `T2a: ${ok ? 'PASS' : 'FAIL'} (${r.same}/${r.gitClean})`, ''].join('\n'), r);
console.log(`T2a ${ok ? 'PASS' : 'FAIL'}`);
```

```ts
import { existsSync, mkdirSync, readdirSync, readFileSync, statSync, writeFileSync } from 'node:fs';
import { homedir } from 'node:os';
import { join, relative } from 'node:path';
import { buildEdges, diffRegions, regionize, TEST_PATH, type FileRegions } from '../src/regions/index.js';
import { ROOT, writeResult } from './lib.js';

const SRC = join(ROOT, 'bench/cache/django-src');
const PATCHES = join(ROOT, 'bench/cache/a_patches');
const CACHE = join(ROOT, 'bench/cache/t4'); mkdirSync(CACHE, { recursive: true });
const PY = join(homedir(), 'Documents/loom/bench/.venv/bin/python');
const HOPS = 3;
const sh = (cmd: string, args: string[], cwd = SRC) => execFileSync(cmd, args, { cwd, encoding: 'utf8', maxBuffer: 1 << 28 });

// 1. index django/ + tests/ once (clean tree)
function walk(d: string, out: string[] = []): string[] {
  for (const f of readdirSync(d).sort()) { const p = join(d, f); if (statSync(p).isDirectory()) walk(p, out); else if (f.endsWith('.py')) out.push(p); }
  return out;
}
sh('git', ['checkout', '-q', '--', '.']);
const maps: FileRegions[] = [];
for (const p of [...walk(join(SRC, 'django')), ...walk(join(SRC, 'tests'))]) maps.push(await regionize(relative(SRC, p), readFileSync(p, 'utf8')));
const { edges } = buildEdges(maps.filter((m) => !m.degraded));
const rev = new Map<string, string[]>();
for (const e of edges) if (e.kind === 'CALLS' || e.kind === 'TESTS') (rev.get(e.to) ?? rev.set(e.to, []).get(e.to)!).push(e.from);
const byId = new Map(maps.flatMap((m) => m.regions.map((r) => [r.id, { path: m.path, r }] as const)));
const testIds = (path: string, qprefix: string) => [...byId.values()].filter((x) => x.path === path && x.r.kind === 'definition' && (x.r.qname === qprefix || x.r.qname.startsWith(qprefix + '.')) && /(^|\.)test/.test(x.r.qname)).map((x) => x.r.id);

// 2. failing test ids from runtests output → region ids
function failed(out: string): { ids: Set<string>; crash: boolean } {
  const ids = new Set<string>(); let crash = !/^Ran \d+ tests?/m.test(out);
  for (const m of out.matchAll(/^(?:ERROR|FAIL): (\S+) \(([\w.]+)\)/gm)) {
    const [name, dotted] = [m[1], m[2]];
    const parts = dotted.split('.');
    // try longest module prefix that exists as tests/<a>/<b>.py
    for (let k = parts.length; k > 0; k--) {
      const file = join('tests', ...parts.slice(0, k)) + '.py';
      if (!existsSync(join(SRC, file))) continue;
      const q = parts.slice(k).join('.');
      for (const id of testIds(file, q || (name === 'setUpClass' ? '' : name))) ids.add(id);
      break;
    }
  }
  return { ids, crash };
}

function runSuite(cache: string): string {
  if (!existsSync(cache)) {
    const r = spawnSync(PY, ['tests/runtests.py', '--parallel', '1', '-v', '0'], { cwd: SRC, encoding: 'utf8', env: { ...process.env, PYTHONPATH: SRC }, maxBuffer: 1 << 28 });
    writeFileSync(cache, (r.stdout ?? '') + (r.stderr ?? ''));
  }
  return readFileSync(cache, 'utf8');
}
// baseline on the clean tree: tests that already fail are excluded from every patch's failure set
const baseline = failed(runSuite(join(CACHE, '_baseline.txt'))).ids;

const rows: Array<{ patch: string; changed: string[]; failed: number; predicted: number; hit: number; crash: boolean }> = [];
for (const patch of readdirSync(PATCHES).filter((f) => f.endsWith('.patch')).sort()) {
  const p = join(PATCHES, patch);
  // definition file: a patched file defining `def <name>(` at module level in the clean tree; when several
  // do (defaultfilters.slugify wraps utils.text.slugify), the one the others import <name> from
  const fname = patch.split('__')[0];
  const files = [...readFileSync(p, 'utf8').matchAll(/^diff --git a\/(django\/\S+\.py)/gm)].map((m) => m[1]);
  const cands = files.filter((f) => new RegExp(`^def ${fname}\\(`, 'm').test(readFileSync(join(SRC, f), 'utf8')));
  const mod = (f: string) => f.replace(/\.py$/, '').replace(/\/__init__$/, '').replaceAll('/', '.');
  const defFile = cands.length === 1 ? cands[0] : cands.find((c) => cands.some((o) => o !== c &&
    new RegExp(`^from ${mod(c).replaceAll('.', '\\.')} import[^\\n]*\\b${fname}\\b`, 'm').test(readFileSync(join(SRC, o), 'utf8'))));
  if (process.env.T4_DRY) { console.log(`${patch}: def=${defFile} cands=${cands.join(',')}`); continue; }
  if (!defFile) { rows.push({ patch, changed: [], failed: 0, predicted: 0, hit: 0, crash: true }); continue; }
  sh('git', ['checkout', '-q', '--', '.']);
  sh('git', ['apply', `--include=${defFile}`, p]);
  const before = maps.find((m) => m.path === defFile)!;
  const after = await regionize(defFile, readFileSync(join(SRC, defFile), 'utf8'));
  const d = diffRegions(before.regions, after.regions);
  const changed = [...d.updated, ...d.tombstoned, ...d.renamed.map((r) => r.from)];
  // predicted: reverse BFS ≤ HOPS, keep test-file definitions
  const seen = new Set(changed); let frontier = [...changed];
  for (let h = 0; h < HOPS; h++) { const nxt: string[] = []; for (const x of frontier) for (const y of rev.get(x) ?? []) if (!seen.has(y)) { seen.add(y); nxt.push(y); } frontier = nxt; }
  const predicted = [...seen].filter((id) => { const x = byId.get(id); return x && TEST_PATH.test(x.path) && x.r.kind === 'definition' && /(^|\.)test/.test(x.r.qname); });
  const f = failed(runSuite(join(CACHE, patch + '.txt')));
  for (const b of baseline) f.ids.delete(b);
  const hit = predicted.filter((x) => f.ids.has(x)).length;
  rows.push({ patch, changed, failed: f.ids.size, predicted: predicted.length, hit, crash: f.crash });
  console.log(`${patch}: failed=${f.ids.size} predicted=${predicted.length} hit=${hit}${f.crash ? ' CRASH' : ''}`);
}
sh('git', ['checkout', '-q', '--', '.']);
const use = rows.filter((r) => !r.crash && r.failed > 0);
const F = use.reduce((a, r) => a + r.failed, 0), P = use.reduce((a, r) => a + r.predicted, 0), H = use.reduce((a, r) => a + r.hit, 0);
const recall = F ? H / F : 0;
writeResult('t4', [
  `T4 sample: 36 A patches reduced to their definition-file hunks; full Django suite, serial`,
  `bar: pooled recall ≥ 0.8 at test-method level over patches that break ≥ 1 test`,
  ...rows.map((r) => `  ${r.patch}: changed=${r.changed.length} failed=${r.failed} predicted=${r.predicted} hit=${r.hit}${r.crash ? ' suite_crash' : ''}`),
  `used=${use.length} breaking-nothing=${rows.filter((r) => !r.crash && r.failed === 0).length} crash=${rows.filter((r) => r.crash).length}`,
  `pooled: failed=${F} predicted=${P} hit=${H} recall=${recall.toFixed(3)} precision=${P ? (H / P).toFixed(3) : '—'}`,
  `T4: ${recall >= 0.8 ? 'PASS' : 'FAIL'} (recall ${recall.toFixed(3)})`, ''].join('\n'), rows);
```

```ts
import { execFileSync } from 'node:child_process';
import { mkdtempSync, readdirSync, rmSync, writeFileSync } from 'node:fs';
import { homedir, tmpdir } from 'node:os';
import { join } from 'node:path';
import { regionMerge } from '../src/regions/index.js';
import { writeResult } from './lib.js';

const RUNS = join(homedir(), 'Documents/loom/bench/runs/e5/team-1/repos');
const g = (cwd: string, ...a: string[]) => execFileSync('git', ['-C', cwd, ...a], { encoding: 'utf8', stdio: ['ignore', 'pipe', 'pipe'] });
const tryG = (cwd: string, ...a: string[]) => { try { return { ok: true, out: g(cwd, ...a) }; } catch (e: any) { return { ok: false, out: String(e.stdout ?? '') }; } };

const out: string[] = []; const rows: any[] = [];
let resolved = 0, sameRegion = 0, other = 0;
for (const scen of readdirSync(RUNS).sort()) {
  const repo = join(RUNS, scen);
  const agents = g(repo, 'for-each-ref', '--format=%(refname:short) %(committerdate:unix)', 'refs/heads/loom/')
    .trim().split('\n').map((l) => l.split(' ')).filter(([r]) => /\/[a-d]$/.test(r)).sort((x, y) => Number(x[1]) - Number(y[1])).map(([r]) => r);
  const base = g(repo, 'merge-base', '--octopus', ...agents).trim();
  const wt = mkdtempSync(join(tmpdir(), 't5-'));
  g(repo, 'worktree', 'add', '-q', '--detach', wt, base);
  const row: any = { scen, order: agents, steps: [] };
  for (const a of agents) {
    const m = tryG(wt, '-c', 'user.name=t5', '-c', 'user.email=t5@x', 'merge', '--no-edit', '-q', a);
    if (m.ok) { row.steps.push({ a, git: 'clean' }); continue; }
    const files = g(wt, 'diff', '--name-only', '--diff-filter=U').trim().split('\n').filter(Boolean);
    const step: any = { a, git: 'conflict', files: [] };
    let allResolved = true;
    for (const f of files) {
      const s = (n: number) => g(wt, 'show', `:${n}:${f}`);
      const r = await regionMerge(f, s(1), s(2), s(3));
      if (r.status === 'merged') { writeFileSync(join(wt, f), r.text); g(wt, 'add', f); step.files.push({ f, class: 'resolved' }); resolved++; }
      else if (r.status === 'conflict') { allResolved = false; step.files.push({ f, class: 'same-region', regions: r.regions.map((x) => x.id) }); sameRegion++; }
      else { allResolved = false; step.files.push({ f, class: 'other', reason: r.reason }); other++; }
    }
    if (allResolved) g(wt, '-c', 'user.name=t5', '-c', 'user.email=t5@x', 'commit', '-q', '--no-edit');
    else g(wt, 'merge', '--abort');                        // v2: not landed; the agent is resumed with the brief
    row.steps.push(step);
  }
  g(repo, 'worktree', 'remove', '--force', wt); rmSync(wt, { recursive: true, force: true });
  rows.push(row);
  out.push(`${scen}: order ${agents.map((a) => a.split('/').pop()).join('→')}`);
  for (const s of row.steps) out.push(`  ${s.a.split('/').pop()}: ${s.git}${s.files ? ' ' + s.files.map((f: any) => `${f.f}=${f.class}${f.regions ? '[' + f.regions.join(',') + ']' : ''}${f.reason ? '(' + f.reason + ')' : ''}`).join(' ') : ''}`);
}
const ok = other === 0;
writeResult('t5', [
  `T5 sample: 6 E5 team-1 repos; agent branches merged in commit-time order; regionMerge on each git-conflicted file`,
  `bar: 0 conflicted files outside {resolved by regionMerge, same-region (lease-serialized)}`,
  ...out,
  `conflicted files: resolved=${resolved} same-region=${sameRegion} other=${other}`,
  `T5: ${ok ? 'PASS' : 'FAIL'} (${resolved} resolved, ${sameRegion} same-region, ${other} other)`, ''].join('\n'), rows);
console.log(`T5 ${ok ? 'PASS' : 'FAIL'}`);
```
