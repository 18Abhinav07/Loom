# Proof Ledger

Every claim the product or the submission makes has one row here. A status changes only with evidence: a command, an output file and the numbers. `refuted` rows stay in the ledger; the spec changes, not the row. Spec §10.1.

Status: `proven` · `refuted` · `partial` (holds under a stated scope) · `open` (owner phase named).
